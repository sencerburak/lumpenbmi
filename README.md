# LumpenBackpack 3000

A simple, modern 3D backpack visualization built with Three.js. Features a procedurally generated backpack model with orbit controls, floating animation, and soft studio lighting. Deployed on YouTube sandbox.

## Run locally

```bash
npx serve .
```

Then open `http://localhost:3000`.

## Controls

- **Drag** to orbit around the backpack
- **Scroll** to zoom in/out
- Watch it gently float and sway
